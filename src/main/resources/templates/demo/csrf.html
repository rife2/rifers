CSRF Protection

A state-changing POST is guarded by before(new CsrfProtected()). The real verification runs out of container: the legitimate form carries the token the server handed out, while a forged cross-site request cannot read it.

The token lives in an HttpOnly cookie and a matching form field. Another site can make the browser send the cookie, but cannot read the field, so its request is refused before the route runs.

POST /transfer moves $100. Only a request with a token matching the cookie is allowed to run.

200 OK
The token matched the cookie, so the route ran: {{v outcome/}}
403 FORBIDDEN
The token did not match, so CsrfProtected refused the request before the route ran.
