Bidirectional Templates

A RIFE2 template is an ordinary file with no logic, HTML here, but XML, SVG, text and JSON work the same way. Pick a state and watch: the template never changes, the Java picks a different named block, and you get a different page. The logic lives in the Java, not the template.

the template, never changes
<!--v body/-->

<!--b welcome-->Welcome, stranger. Sign in to see your dashboard.<!--/b-->
<!--b dashboard-->Hi <strong><!--v name/--></strong>! Tags: <!--v tags/--><!--/b-->
<!--b tag--><span class="demo-tpl-tag"><!--v label/--></span><!--/b-->
the rendered result

The same logic-less template renders both states. Change Show and only the Java's choice of block changes, never the template.
