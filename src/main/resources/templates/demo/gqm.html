Generic Query Manager

The manager derives the table straight from a plain Book bean, then saves, restores and counts rows with single method calls. No SQL, no row mapping, no annotations.

{{v count/}} books in the database

Every request builds a private in-memory database, seeds two books, saves yours next to them, reads them all back through the manager, then discards the database. Nothing is kept between requests, so it is only here to show the save and restore round-trip. Saving also sends an HX-Trigger response header, so the page flashes a toast from a client event with no extra request.
